# 青竹 · Qingzhu

一个手写的单页博客。没有框架、没有构建步骤、没有外部字体和图片，断网也能打开。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构、社交图标链接 |
| `style.css` | 排版、深浅色、响应式、背景网格 |
| `app.js` | 文章与碎片数据、搜索筛选、展开阅读、鼠标背景效果 |
| `favicon.svg` | 图标 |

## 本地打开

直接双击 `index.html` 即可。想让文章链接（`#post-xxx`）和复制链接功能完全正常，用本地服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 改内容

- **文章**：`app.js` 里的 `posts` 数组，文件开头有现成的模板注释，照抄一份改文字就行。标签要同时加进 `tags` 数组才会出现在筛选栏。
- **碎片**：`app.js` 里的 `scraps` 数组，每项 `date` + `text`。
- **社交图标**：`index.html` 里搜 `socials`，把 `href="#"` 换成自己的主页地址。
- **签名、联系方式、关于**：都在 `index.html` 里。

## 背景与签名

两层网格加一层 canvas：底层是淡网格，上层用 `radial-gradient` 做遮罩，跟着鼠标移动并显示蓝色准星；canvas 在网格交点画点，鼠标靠近会被推开再弹回。首页的手写签名逐字拆开，跟着鼠标和一阵慢风轻轻飘。

以下情况会自动降级：开启系统「减少动态效果」、触屏设备、窄屏（格子从 80px 收到 56px、点阵与飘动关闭）。主题跟随系统，也可以点右上角手动切换，选择存在 `localStorage`。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索 |
| `Esc` | 关闭搜索 / 收起文章 |

## 部署

纯静态文件，放 GitHub Pages、Cloudflare Pages 或任意静态托管都可以，根目录直接指向仓库根，不需要构建命令。
