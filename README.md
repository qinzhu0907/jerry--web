# Jerry — 写点东西

一个手写的单页博客。没有框架、没有构建步骤、没有外部字体和图片，断网也能打开。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 排版、深浅色、响应式、背景网格 |
| `app.js` | 文章与碎片数据、搜索筛选、展开阅读、鼠标背景效果 |
| `favicon.svg` | 图标 |

## 本地打开

直接双击 `index.html` 即可。想让文章链接（`#post-xxx`）和复制链接功能完全正常，用本地服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 改内容

- 文章：`app.js` 里的 `posts` 数组。每项包含 `id`（决定链接）、`no`、`date`、`tag`、`minutes`、`title`、`desc`、`body`（段落数组）。标签要加进同一文件里的 `tags` 数组才会出现在筛选栏。
- 碎片：`app.js` 里的 `scraps` 数组，每项 `date` + `text`。
- 联系方式、简介、关于：都在 `index.html` 里。

## 背景效果

两层网格加一层 canvas：底层是淡网格，上层用 `radial-gradient` 做遮罩，跟着鼠标移动并显示蓝色准星；canvas 在网格交点画点，鼠标靠近会被推开再弹回。鼠标停在「碎片」格子上时，焦点会吸附到格子中心。

以下情况会自动降级：开启系统「减少动态效果」、触屏设备、窄屏（格子从 80px 收到 56px、点阵关闭）。主题跟随系统，也可以点右上角手动切换，选择存在 `localStorage`。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `/` | 聚焦搜索 |
| `Esc` | 关闭搜索 / 收起文章 |

## 部署

纯静态文件，放 GitHub Pages、Cloudflare Pages 或任意静态托管都可以，根目录直接指向仓库根，不需要构建命令。
